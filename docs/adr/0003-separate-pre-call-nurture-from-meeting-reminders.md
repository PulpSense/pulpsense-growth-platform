# Separate pre-call nurture from meeting reminders

Pre-call Nurture is an editable Brevo Communication Flow whose first message confirms the booking seconds after verification, while Meeting Reminders are appointment-relative transactional messages scheduled directly by Trigger.dev and sent automatically through an authenticated personal Gmail account without draft approval. Both follow a rescheduled appointment's new time and stop on cancellation, but reminders independently verify that the appointment is still active immediately before delivery so cancelled or stale schedules cannot produce false reminders.
